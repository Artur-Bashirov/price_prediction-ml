# Price Prediction ML

Модель бинарной классификации для прогнозирования направления движения цены финансового актива на следующий торговый день (Up / Down) на основе исторических данных OHLCV и технических индикаторов.

## О проекте

Проект реализует пайплайн машинного обучения для предсказания направления цены. Модель обучена на дневных котировках за период 2014–2024 гг. и демонстрирует статистически значимое превосходство над базовой линией (Dummy Classifier) по метрикам Accuracy и ROC-AUC.

**Ключевые результаты на отложенной тестовой выборке (2022–2024):**

| Модель | Accuracy | ROC-AUC |
| --- | --- | --- |
| LightGBM | 0.5610 | 0.5583 |
| RandomForest | 0.5020 | 0.5098 |
| Dummy (baseline) | 0.4512 | 0.4514 |

Для задачи прогнозирования дневных доходностей финансового рынка такой результат является реалистичным и свидетельствует об отсутствии переобучения.
