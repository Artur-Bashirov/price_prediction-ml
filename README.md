##  Описание

Проект реализует полноценный **ML-пайплайн** для предсказания направления дневной доходности:

-  Строгая **временная валидация** (хронологический hold-out + `TimeSeriesSplit`)
-  Корректная **инженерия признаков** без утечки будущего (`shift` → `rolling`)
-  Проверка **стационарности** рядов (ADF-тест)
-  **Винзоризация** выбросов, рассчитанная только на train
-  Сравнение с **Dummy-базовой линией**
-  Готовые артефакты для **продакшн-инференса**

Модель обучена на дневных котировках за период **2014–2024 гг.** и демонстрирует статистически значимое превосходство над случайным угадыванием.

##  Использование

### Обучение модели

Основные этапы:

1. Загрузка данных (`test_ds_1.xlsx`)
2. Feature Engineering (31 признак)
3. Проверка стационарности (ADF-тест)
4. Хронологическое разделение Train/Test (80/20)
5. Обучение моделей: **RandomForest**, **LightGBM**, **Dummy**
6. Кросс-валидация (`TimeSeriesSplit`, 5 folds)
7. Сохранение артефактов в `artifacts/`

### Инференс на новых данных

```python
import joblib
import pandas as pd

# Загрузка артефактов
model = joblib.load("artifacts/best_model.pkl")
features = joblib.load("artifacts/feature_cols.pkl")

# Подготовка новой строки (OHLCV за завершённый торговый день)
new_data = pd.DataFrame([{
    "open": 2100.0, "high": 2150.0, "low": 2080.0,
    "close": 2130.0, "vol": 1500000,
    # ... остальные признаки рассчитываются пайплайном
}])

# Предсказание
pred = model.predict(new_data[features])[0]
proba = model.predict_proba(new_data[features])[0]

print(f"Prediction: {'Up' if pred == 1 else 'Down'}")
print(f"Probabilities: Down={proba[0]:.3f}, Up={proba[1]:.3f}")
```

### Пример вывода

```
Дата 'нового' дня: 2022-07-07
Предсказание: Down (0)
Вероятности: Down=0.711, Up=0.289
```

##  Архитектура модели

Модель реализована как `sklearn.Pipeline` из двух шагов:

```
Pipeline
├── ColumnTransformer (preprocessor)
│   ├── StandardScaler     → 27 числовых признаков
│   └── passthrough        → 4 циклических (sin/cos)
└── LGBMClassifier
    ├── n_estimators = 300
    ├── learning_rate = 0.05
    ├── max_depth = 5
    ├── num_leaves = 31
    ├── subsample = 0.8
    ├── colsample_bytree = 0.8
    └── reg_alpha/lambda = 0.1
```

##  Данные и Feature Engineering

### Исходные данные

| Параметр | Значение |
|:---|:---|
| Источник | `test_ds_1.xlsx` |
| Объём | 2507 записей |
| Период | 16.06.2014 — 14.06.2024 |
| Классы | Up: 51.3%, Down: 48.7% |

### Признаки (31 шт.)

| Группа | Признаки | Обоснование |
|:---|:---|:---|
| **Лаги** | `close_lag1/2/3`, `vol_lag1` | Базовая память ряда |
| **Доходности** | `return_1d`, `return_lag_2/3`, `return_intraday` | Стационарные признаки |
| **Тренды (SMA)** | `price_to_sma5/20` | Отношение цены к скользящим средним |
| **Волатильность** | `volatility_5/20`, `hl_range` | Разброс и диапазон |
| **Объём** | `vol_sma5`, `vol_ratio` | Относительный объём |
| **Технические** | `rsi_14` | Индекс относительной силы |
| **Время** | `weekday/month sin/cos`, `day_of_year` | Циклическое кодирование |

>  **Важно**: все лаги и rolling-признаки рассчитываются по схеме `shift → rolling`, что гарантирует отсутствие **look-ahead bias**.

##  Ограничения и этика

### Известные ограничения

-  **Потолок точности**: Accuracy ~56% реалистичен для дневного таймфрейма эффективного рынка, но **недостаточен** для гарантированной прибыли без риск-менеджмента.
-  **Нет фундаментальных данных**: модель игнорирует макро-новости, отчёты, геополитику.
-  **Смещение предсказаний**: модель чаще предсказывает класс `Down`.
-  **Concept Drift**: паттерны 2014–2024 могут устареть при смене рыночного режима.

### Допустимое использование 

- Исследовательские и образовательные цели
- Базовые сигналы в алгоритмических стратегиях
- Meta-feature в ансамблях
- Фильтр для отсеивания заведомо плохих сделок

### Запрещённое использование 

- Высокочастотный трейдинг (HFT)
- Принятие крупных финансовых решений **без человеческого контроля**
- Использование как единственного источника истины для входа в позицию

### Меры по снижению рисков

-  **Probability Thresholding** — открывать позиции только при уверенности > 65%
-  **Ансамблирование** с другими алгоритмами
-  **Регулярное переобучение** на скользящем окне
-  **Ручная проверка «серой зоны»** (вероятность ≈ 0.5)
